# AI-аудитор воспроизводимости научных исследований

Проект сопоставляет научную статью в PDF с зафиксированной версией её
репозитория. MVP охватывает экспериментальные параметры и характеристики
наборов данных. Потенциальные расхождения подтверждает эксперт. При неполных
источниках используйте статус «недостаточно материалов для проверки».

## Среда

- Запускайте команды из корня репозитория. Используйте Python 3.10+
  и локальное окружение `.venv`.
- Устанавливайте зависимости командой `.venv/bin/python -m pip install .`.
- Разрабатывайте с расчётом на CPU и 16 ГБ RAM. На этапе подготовки данных
  не запускайте обучение и не добавляйте тяжёлые ML-библиотеки.

## Материалы и разработка

- Сохраняйте исходный DOCX и предоставленные материалы `project_sample/`
  без изменений. Записывайте новые результаты в отдельный каталог.
- Для первого этапа используйте локальный split `real` SciCoQA.
  Шестистрочный JSONL предназначен для просмотра схемы. Полный локальный
  снимок находится в `project_sample/data/raw/scicoqa_real.parquet`.
- Сохраняйте `discrepancy_id` и ссылки на источники. У одной пары
  «статья — репозиторий» может быть несколько расхождений. Не заполняйте
  отсутствующие метки догадками.
- `project_sample/inspect_scicoqa.py` скачивает данные и пишет файлы в
  `data/` относительно текущего каталога. Для проверки установки
  импортируйте библиотеки напрямую и читайте локальные данные без записи.
- Реализуйте алгоритм аудита отдельной задачей после подготовки среды.
