## Воспроизведение

Из корня AI_auditor выполните `bash data_review/lr_explicit_experiment/commands.sh`. В [commands.sh](commands.sh) сохранены все три команды. Для восстановления локальных входов используйте `pdf_url`, `pdf_sha256`, `repo_url` и `commit` из манифеста. Команды ожидают два PDF по путям `/tmp/ai-final-eval/crd/paper.pdf` и `/tmp/ai-final-eval/sam/iccv.pdf`, а Git-объекты в соседних bare-репозиториях `git`. Исследовательский код для этих прогонов не нужен.

`--paper-section` и `--paper-context` задают заголовок и контекст утверждения в PDF. `--paper-model-pair` проверяет пару учитель/студент в одной колонке таблицы, которую можно указать через `--paper-table`. Повторяемый `--recipe-arg=FLAG=VALUE` сопоставляет литеральные аргументы команды, а `--recipe-context` сопоставляет вводящий её текст README. Для явного рецепта поддержана статическая цепочка Python → argparse → настройки → SGD. Если цепочка не разрешается, `issue_codes` различает ошибку извлечения и проблему выбора рецепта. В JSON сохраняются доступные промежуточные подтверждения.

## Изменения и тесты

- `ai_auditor/__main__.py` добавляет опциональные аргументы.
- `ai_auditor/initial_lr.py` подключает явный выбор и коды причин, сохраняя прежние поля JSON.
- `ai_auditor/experiment_lr.py` проверяет контекст PDF, выбирает команду и статически прослеживает LR.
- `ai_auditor/flag_lr.py` переиспользует разбор аргументов с опциональным допуском коротких флагов и путей.
- `tests/test_initial_lr.py` покрывает выбор между похожими командами, приоритет переопределения из команды и последующих присваиваний, а также отказ при неразрешённом присваивании.

`.venv/bin/python -m unittest discover -s tests` — 31 тест прошёл. Все три контрольные команды завершились с кодом 0. `git diff --check` прошёл.
