Номера страниц отсчитываются от первого листа PDF.

## Независимость и аргументы

Сверили названия, идентификаторы статей и репозитории с локальной очередью SciCoQA и [реестром исключений](excluded_studies.tsv). В очереди поиск `learning rate|rotat` вывел ELECTRA, EQFace и пилот по углу, которые уже исключены. Пять принятых к рассмотрению кейсов взяты из внешних публикаций и не получили вымышленных `discrepancy_id`. Реестр дополняет исходный список исключений исследованиями из первого отложенного прогона. FedOptim числится кейсом разработки.

В TSV сохранены версии и SHA-256 PDF, полные коммиты, страницы и строки кода, аргументы в массиве `cli_argv`, а также происхождение ручных подсказок в `manual_hint`. В будущей оценке эти аргументы передаются после `python -m ai_auditor` из каталога набора. Для DIVA домен передаётся флагом CLI. Для выбора конкретного конфига Hydra, варианта CRD и файлов GeqShift текущий CLI не предоставляет подходящего селектора. Эти подсказки предназначены для приёмки разметки и не подставляются в аргументы. Поддержка каждого такого маршрута текущим CLI пока не проверялась.

## Снимок и входы

- [cli_snapshot.tar.gz](cli_snapshot.tar.gz) содержит рабочую версию `ai_auditor/` и `pyproject.toml`. SHA-256 архива указан в [cli_snapshot.sha256](cli_snapshot.sha256) вместе с хешами файлов. База рабочего дерева — `bae35a189b48c0b77559888f000a590a49eb1f19`. Архив включает изменения рабочего дерева поверх этого коммита.
- [runtime.lock.txt](runtime.lock.txt) фиксирует установленные версии для Python 3.12.3. Версия Git — 2.43.0. Запись `ai-auditor==0.1.0` нормализована из временного пути установки и обозначает локальный пакет из архива. Для воспроизведения установите зафиксированные сторонние зависимости и сам пакет из распакованного снимка.
- Для каждого кейса сохраните PDF из `pdf_url` в `inputs/<case_id>/paper.pdf` и проверьте `pdf_sha256`. Получите указанный коммит из `repo_url` в bare-репозиторий `inputs/<case_id>/repo.git` и проверьте `git cat-file -t <commit>`. Достаточно Git-объектов, рабочая копия исследования не нужна. Пути внутри `cli_argv` относительны к каталогу набора.
- Проверка набора состояла в разборе PDF и статическом чтении Git-объектов. CLI и исследовательский код не запускались. Статус приёмки всех строк — `pending`.
