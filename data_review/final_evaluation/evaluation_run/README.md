## Угол поворота

[DIVA](FINAL-angle-diva.json), единственный кейс угла. Ожидалось `match` и `75 / 75` градусов. Получено `insufficient_materials` и `null / null` за **0.231 с**. Стр. 5 в JSON действительно даёт общее описание Rotated MNIST и тестового M75°, поэтому это корректное частичное свидетельство. Привязка к варианту с дополнительным M30° из табл. 2 на стр. 6 отсутствует. Кодовых доказательств нет. CLI ищет цепочку к файлу повернутого изображения, а загрузчик DIVA поворачивает изображения в памяти и возвращает их как `test_data`. Точный статус для угла получен в **0/1** кейсов.

## Файлы прогона

Для каждого кейса сохранены исходный JSON CLI, `*.run.json` с полной командой, рабочим каталогом, кодом выхода и длительностью, а также `*.stderr.txt`. Длительность измерена от запуска процесса до завершения, без подготовки входов и скачивания. Для воспроизведения после очистки временной папки распакуйте тот же архив и восстановите относительные пути `inputs/<case_id>/` по [манифесту выборки](../cases.tsv). Далее используйте сохранённый массив аргументов и тот же набор версий зависимостей.
