# Повторная проверка доказательств PDF

Повторены все семь запусков из [независимой оценки](../independent_evaluation/README.md). Массивы аргументов в `*.run.json` совпадают с исходными, дополнительных селекторов не использовано. SHA-256 PDF и полные Git-коммиты проверены исходным запускатором. Ошибок запуска **0/7**, статус всех аудитов `insufficient_materials`. Исследовательский код не исполнялся.

Во всех семи новых JSON `code_value=null`. Новые правила PDF используют явную область действия списка гиперпараметров и продолжение определения тестовых доменов. Два разных базовых LR для одного контекста сохраняются как кандидаты с `paper_lr_ambiguous`. Отдельные тесты проверяют отказ на LR, квалифицированном другим датасетом, и на угле из обучающего или другого тестового домена.

Полный набор — **45 тестов прошли** через `.venv/bin/python -m unittest discover -s tests`. Исходный манифест и снимок проверены по SHA-256. Исходные JSON и эталон сохранены.

Повторить из корня проекта можно командой `bash data_review/pdf_evidence_recheck/commands.sh /tmp/ind-eval /tmp/pdf-evidence-rerun`. Если локальные входы отсутствуют, третьим аргументом передайте `--fetch`. Скрипт использует зафиксированные входы, исходные аргументы и новый [снимок CLI](cli_snapshot.tar.gz).
