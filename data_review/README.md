# Ручная разметка SciCoQA

Очередь `review_queue.tsv` содержит 26 кандидатов из локального split `real` после первичного отбора. Исходные поля SciCoQA служат подсказками для поиска доказательств. Пустые поля ручной разметки означают, что проверка ещё не выполнена.

## Как проверять строку

1. Откройте указанную версию статьи и репозитория. Если версия статьи отсутствует в исходных данных, запишите фактически проверенную версию в `review_notes`. Проверьте, что утверждение статьи и значение в коде относятся к одному эксперименту, включая модель, конфигурацию и часть датасета.
2. Укажите в `review_category` категорию `training_parameter` или `dataset`, а в `field` — проверяемый параметр или характеристику. Запишите сопоставимые значения, исходные цитаты и координаты доказательств. Для статьи используйте страницу и раздел или номер таблицы. Для кода укажите путь и строки на проверенном commit.
3. Выберите статус по таблице. Если сведений недостаточно, поясните в `review_notes`, чего не хватило и какие источники удалось проверить.
4. Присвойте `study_id` после проверки идентичности исследования. Версии и альтернативные URL одной работы получают одинаковый ID. Все строки с одним таким ID должны при разделении попадать целиком в одну выборку. Перед разделением проверьте возможные дубликаты работ по названию, авторам и идентификаторам публикации.

| `review_status` | Условие |
| --- | --- |
| `confirmed_discrepancy` | Значения для одного эксперимента явно различаются. |
| `confirmed_match` | Значения для одного эксперимента явно совпадают. |
| `insufficient_materials` | Одно из значений, нужная версия источника или связь с экспериментом не подтверждаются. |
| `out_of_scope` | Кейс вне двух категорий MVP. |

## Как дополнить набор

Добавляйте отдельно проверенные соответствия и случаи недостаточности материалов на уровне конкретного утверждения. Для новых случаев заведите собственный идентификатор и оставьте `discrepancy_id` пустым, если записи SciCoQA нет. Фиксируйте происхождение и версию источников по тем же правилам. Группируйте такие строки вместе с остальными строками того же исследования. Распределение по выборкам имеет смысл после первичной ручной разметки и проверки покрытия статусов.

## Как создать очередь из локального снимка

Из корня репозитория выполните `.venv/bin/python data_review/prepare_review.py`. Скрипт создаёт TSV только при его отсутствии, чтобы сохранить уже внесённую разметку.
