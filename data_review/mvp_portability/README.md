## Выборка и процедура

Проверены четыре новые пары из Python-репозиториев. Для исключений использованы [первый независимый отчёт](../independent_evaluation/README.md), [регрессия CSD](../csd_rotation_recheck/README.md), исходные манифесты и реестр исключений. В выборке три проверки LR и одна проверка угла. Обоснованное расхождение угла не найдено. Результат ARM показывает один новый маршрут тестового датасета с поворотом в памяти. По нему нельзя оценить обнаружение расхождений по углу.

[Манифест](cases.tsv) записан и [зафиксирован SHA-256](cases.sha256) до первого аудита. Он содержит версии и хеши PDF, полные коммиты, ручные эталоны со страницами и строками, исходные команды и подсказки. Эталон размечал Codex по тексту статьи и статическому чтению Git-объектов. Для LoRA нужна экспертная проверка сопоставимости опубликованного рецепта CoLA и группы LoRA из табл. 9. Другие эталоны внешним экспертом пока не проверены. Для LR сравнивается базовая настройка перед прогревом. Для SimCLR она учитывает масштабирование по размеру батча.

Все четыре команды запущены из распакованного снимка через Python локальной `.venv`. Проверены контрольные суммы PDF и точные коммиты. Сохранены исходные JSON, stderr и `*.run.json` с фактическими аргументами, кодом выхода и временем. Исследовательский код не выполнялся. Манифест, команды и эталоны после запуска сохранены.

## Воспроизведение

Из корня DataLinux, с закреплёнными версиями `.venv`:

```bash
.venv/bin/python data_review/mvp_portability/run.py \
  --inputs /tmp/mvp-inputs --output /tmp/mvp-portability-rerun
```

Если входов нет, добавьте `--fetch`. Запускатор восстановит PDF и Git-объекты по манифесту, проверит хеши и выполнит сохранённые аргументы из распакованного снимка.
