## Новая выборка

Четыре новые пары. Исходные манифесты и реестр исключений использованы для сверки исследований. BERT ранее рассматривался при поиске источников, но не входил в оценку или разработку. Эталон BERT отмечен как предварительное различие статьи и официального рецепта: модель и задача совпадают, однако README прямо оговаривает другие гиперпараметры, в том числе батч и число эпох. Это не свидетельство о фактическом запуске авторов. Эксперт должен подтвердить приемлемость такого объёма сравнения. Эталоны составил Codex ручным чтением статей и Git-объектов. Внешняя экспертная проверка не проводилась. Надёжного расхождения по углу в новой выборке нет.

[Манифест](cases.tsv) зафиксирован по SHA-256 до первого запуска. Содержит версии и хеши PDF, коммиты, фрагменты статьи, строки кода, эталон и команды. Ручные подсказки на новых кейсах ограничены этапом, а для DAA также названием датасета и доменом. Знание конкретного рецепта в эталоне не переносилось в дополнительные параметры CLI. Для каждого нового кейса выполнена одна команда. Демонстрационные запуски с более подробными селекторами показаны отдельно и в метрики не включены.

Знаменатель для подтверждённых значений — кейсы с численным эталоном на соответствующей стороне. Для ложных сигналов — подтверждённые совпадения. На GAT с недостаточными материалами ложных сигналов также 0/1. Без предварительного эталона BERT завершённых сравнений **0/2** и показатель пропущенных расхождений неприменим.

Выборка подтверждает, что CLI переносит извлечение явно указанного датасетного LR и сохраняет его при отсутствии сравнимого рецепта. Она не подтверждает сквозную переносимость на этих новых типах структуры документа и запуска. Данных для оценки чувствительности по повороту нет. Нулевое число ложных сигналов при отсутствии завершённых сравнений не позволяет судить о точности сигналов. Для защиты демонстрировать проверенные маршруты отдельно от новой выборки.

## Воспроизведение

Из корня DataLinux: `.venv/bin/python data_review/defense_mvp/run.py --inputs /tmp/defense-inputs --output /tmp/defense-control-rerun`. При отсутствии входов добавьте `--fetch`. Запускатор проверяет SHA-256 PDF, полные коммиты, архив и манифест. Исходные JSON, stderr, коды выхода и аргументы сохранены в runs/. Исследовательский код не запускался. Исходные результаты предыдущих оценок сохранены. [Сценарий защиты](DEMO.md)
