## Повторный прогон

Из корня проекта с настроенной `.venv`:

```bash
bash data_review/lr_portability/reproduce.sh
```

Скрипт скачивает версии PDF по URL и сверяет SHA-256, затем получает точные
коммиты в отдельные bare-репозитории. Команды аудита запускаются из корня
проекта, полный JSON и строки запуска сохраняются в `replay/`. Можно передать
каталог кэша и каталог вывода первым и вторым аргументами. Папка `results/`
содержит оригинальный прогон. Пути `/tmp` в его логах относятся к тому запуску.

Использованы CLI из коммита `bae35a189b48c0b77559888f000a590a49eb1f19`,
Python 3.12.3, PyMuPDF 1.28.2 и Git 2.43.0. Доказательства проверялись
чтением PDF, README, конфигураций и файлов закреплённых Git-коммитов.

Повтор с пустым кэшем и свежей загрузкой источников дал побайтно
одинаковый JSON для всех трёх строк.
