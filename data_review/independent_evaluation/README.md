## Выборка и процедура

Просмотрена локальная очередь SciCoQA. Поиск `learning rate|rotat` вернул ELECTRA, EQFace и MatchDG, которые уже использовались. Новые пары отобраны по первоисточникам после сверки с реестром исключений, первым отложенным прогоном, итоговым набором и последующими регрессионными отчётами. Взято пять кейсов LR и два кейса угла. Подтверждённого расхождения угла не найдено. В частности, статья DGviaER задаёт поворот по часовой стрелке, а закреплённый репозиторий публикует рецепт PACS. Без рецепта Rotated MNIST направление в коде установить нельзя.

[Манифест](cases.tsv) с SHA-256 PDF, полными коммитами, ожидаемыми статусами, страницами, строками, точными аргументами CLI и источниками подсказок зафиксирован [контрольной суммой](cases.sha256) до первого запуска. Эталон подготовил Codex путём ручной сверки первоисточников. Независимой человеческой проверки пока нет. Экспертное подтверждение прежде всего требуется для потенциального расхождения S5 и выбранной группы параметров. Эталон LR для S5 и DDPM сравнивает базовую настройку до прогрева. Для DCGAN и ResNet эталон относится к описанному опубликованному рецепту и значению LR. У DCGAN опубликованный рецепт отличается размером батча, у ResNet репозиторий содержит переимплементацию. По этому срезу нельзя делать выводы о частоте расхождений во всех исследованиях.

Аудит запускался из распакованного снимка на локальной `.venv` с неизменными аргументами `cli_argv` и изоляцией Python через `-E -s`. Проверены семь SHA-256 PDF и семь полных коммитов. Каталог `runs/` содержит исходный stdout JSON, stderr и `*.run.json` с фактической командой, кодом выхода и временем. Исследовательский код не выполнялся. После запуска манифест и эталон остались неизменными.

Воспроизведение из корня проекта с уже имеющимися входами:

```bash
.venv/bin/python data_review/independent_evaluation/run.py \
  --inputs /tmp/ind-eval --output /tmp/ind-eval-rerun
```

При отсутствии входов добавьте `--fetch`. Скрипт использует закреплённые источники из манифеста, сверяет их и исключает загрузку из замера времени.

## Метрики

| Категория | Точный статус | Найдено эталонных расхождений | Ложные сигналы среди подтверждённых совпадений | Отказ при достаточных доказательствах | Ошибки запуска |
|---|---:|---:|---:|---:|---:|
| Начальный LR | 1/5 | 0/1 | 0/3 | 4/4 | 0/5 |
| Угол тестового домена | 1/2 | 0/0, неприменимо | 0/1 | 1/1 | 0/2 |

Точный статус включает корректный `insufficient_materials`. Отказ при достаточных доказательствах использует знаменатель из эталонных совпадений и расхождений. Ложные сигналы измерены на подтверждённых совпадениях. На двух кейсах с недостаточными материалами сигналов также не было, **0/2**. Для целевых экспериментов с известными значениями ссылки в JSON полностью подтвердили значение из PDF в **0/4** LR-кейсов и **0/2** кейсов угла, а значение в коде в **0/4** LR-кейсов и **0/1** кейсов угла. Эталонный угол DGviaER берётся из направления поворота в статье. Значение кода для него неизвестно.
